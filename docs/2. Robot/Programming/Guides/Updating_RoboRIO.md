# Updating the RoboRIO

The RoboRIO needs to be updated every year in order to be able to run the newest WPILib code.
The tools we use for that is:

- FRC Game Tools from NI Package Manager
- Balena Etcher
- SD Card Reader

1. Install the latest RoboRIO Image from the RoboRIO Imaging Tool. File located in `C:\Program Files (x86)\National Instruments\LabVIEW 2025\project\roboRIO Tool` by default. (Insert image of RoboRIO Imaging Tool)
2. Use Balena Etcher to etch the RIO Image onto an SD Card.
3. Insert SD Card into RoboRIO to flash the new image.
